# REFACTORING.md

## Выполненные улучшения

1. **Устранено дублирование кода**:  
   Логика поиска задачи по ID вынесена в функцию `find_task_by_id()`.

2. **Разделена длинная функция `index()`**:  
   Ответственность разделена между `get_filtered_tasks()` и `get_stats()`.

3. **Улучшена совместимость с облаком**:  
   Добавлена поддержка переменной окружения `PORT` для Render.

Эти изменения повысили читаемость, тестируемость и поддерживаемость кода.
